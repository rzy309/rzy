JavaScript 两种定时器

setTimeout（一次性）· setInterval（循环）· 荣子祎
一、setTimeout — 一次性定时器 延迟 N 毫秒后执行一次
// 语法： var rzy_timerId = setTimeout(function() { console.log('3 秒后只执行这一次'); }, 3000); // 清除：取消尚未触发的定时器 clearTimeout(rzy_timerId);
🔵 特点 只在"到时间"时触发 一次，然后自动结束。 常用于延迟显示、动画、提示消息。

二、setInterval — 循环定时器 每隔 N 毫秒反复执行
// 语法： var rzy_timerId = setInterval(function() { console.log('每 1 秒打印一次'); }, 1000); // 清除：停止循环 clearInterval(rzy_timerId);
🔴 特点 每隔固定时间 反复触发，不会自动停止！ 记得及时 clearInterval，否则页面会卡爆。
