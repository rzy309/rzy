一、JSON 是什么

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式， 广泛用于前端与后端之间传数据。 它长得像 JS 对象，但有严格的语法规则：

  • 键名（key）必须用双引号括起来："name"
  • 字符串值也必须用双引号："荣子祎"
  • 可以有 6 种值类型：字符串、数字、布尔、null、数组、对象
  • 不能写函数、不能写注释、不能有多余逗号

三、JSON.stringify() 与 JSON.parse()
// JS 对象 → JSON 字符串 var rzy_obj = { name: '荣子祎', age: 20, skills: ['HTML','CSS','JS'] }; var rzy_str = JSON.stringify(rzy_obj); // → '{"name":"荣子祎","age":20,"skills":["HTML","CSS","JS"]}' // JSON 字符串 → JS 对象 var rzy_back = JSON.parse(rzy_str); console.log(rzy_back.name); // → "荣子祎"
